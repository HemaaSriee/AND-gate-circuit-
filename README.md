# AND-gate-circuit-
Circuit analysis for AND gate 

AND GATE CIRCUIT
1. Aim
To design and construct a simple AND gate circuit using basic electronic components to demonstrate the logical AND operation.
2. Problem Statement
In digital electronic circuits, logical operations are used to control the output based on multiple input conditions. An AND gate produces a HIGH output only when all its inputs are HIGH.
A simple AND gate circuit is required to demonstrate how multiple input conditions control a single output.
3. Proposed Solution
The proposed system uses an AND gate IC, input switches, LEDs, resistors, and a DC power supply.
The two inputs are controlled using switches. The output LED glows only when both inputs are HIGH (logic 1).
Push buttons / Input switches
Breadboard
5V DC Power Supply
Jumper Wires
5. Circuit Working
The AND gate IC 7408 is used to perform the logical AND operation.
The circuit has two inputs, A and B.
The output depends on the logic levels of both inputs.
When both inputs are LOW (0), the output is LOW (0).
When either one input is HIGH (1), the output remains LOW (0).
When both inputs are HIGH (1), the output becomes HIGH (1), and the LED glows.
Thus, the AND gate produces a HIGH output only when both inputs are HIGH

6. Procedure
Place the 7408 AND gate IC on the breadboard.
Connect pin 14 to the +5V supply.
Connect pin 7 to Ground (GND).
Connect two input switches to the AND gate inputs (pins 1 and 2).
Connect the output pin (pin 3) to an LED through a current-limiting resistor.
Connect the LED circuit to Ground.
Check all connections carefully.
Switch ON the 5V power supply.
Change the input switch combinations (00, 01, 10, and 11).
Observe the output LED for each combination and verify the truth table.
